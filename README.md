## ⚡ Overview

This repository contains the source code for my personal developer portfolio. Built as a blazing-fast, single-page vanilla web application, it serves as a central hub for my technical projects, hackathon achievements, and professional background without the overhead of heavy JavaScript frameworks.

**Key Features:**
* **Zero Dependencies:** Pure HTML and CSS for maximum performance and instant load times.
* **Project Showcase:** Detailed breakdowns of my core backend and distributed systems projects (e.g., Conduit AI, CipherVault).
* **Responsive UI:** Fluid layout that scales perfectly from mobile devices to desktop monitors.
* **Vercel Edge Deployment:** Continuously deployed and globally distributed via Vercel.
